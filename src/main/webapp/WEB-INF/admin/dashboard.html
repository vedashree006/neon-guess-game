    Definitions

    Visitor
    An anonymous browser with the analytics cookie (random id, no personal data). Only visitors who accepted analytics are counted.
    Unique visitor
    One visitor id, counted once however often it returns.
    Visit
    A run of activity by one visitor. It ends after the inactivity timeout; coming back later starts a new visit.
    Page view
    One page load. Heartbeats and dashboard polling are never page views.
    Active visitor
    A visitor with activity inside the activity window. A live estimate, not an exact count.
    Game session
    A game in progress in a server session. Includes people who declined analytics.
    Authenticated user
    A signed-in admin. Visitors are never authenticated users.
    Retention
    Raw analytics are deleted after - days.
