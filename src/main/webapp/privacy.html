What happens when you play

The game keeps your current game, including the secret number, in a server session. When a game ends, your player name (a nickname you choose; please do not use your real name), the result, the number of attempts and the time are saved and shown publicly on the leaderboard. Legal basis: providing the game you asked for (Art. 6(1)(b) GDPR) and our interest in a working leaderboard (Art. 6(1)(f) GDPR). Leaderboard entries are kept until they are removed; write to the address above to have one deleted.

For abuse protection the server briefly keeps your IP address in memory to limit request rates. It is not written to the database and disappears within minutes. Your hosting provider may log requests as part of operating the server: [HOSTING PROVIDER / LOG RETENTION].

Analytics

If you accept analytics, the server stores the random visitor id, the time of your visits, which page you opened (path only, never a query string), and game events (started, won or lost, number of attempts). It stores no IP address, no browser fingerprint, no name and no e-mail address. Only the site owner sees the results, as totals and charts. Raw analytics data is deleted after 365 days by default. We cannot guarantee this setup suits every legal situation; the choice is yours.
